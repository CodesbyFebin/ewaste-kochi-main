# Policy Statement
Ewaste Kochi prioritizes data security and privacy for all clients.
We comply with:
- The Digital Personal Data Protection (DPDP) Act 2023 (India)
- NIST 800-88 Guidelines for Media Sanitization
- ISO 27001 Information Security Standards
- GDPR and related international privacy regulations

All reported vulnerabilities will be acknowledged within 48 hours.
We do not accept responsible disclosure via public social media.

# Security Standards
- Data encryption: AES-256 for stored data, TLS 1.3 for transmission
- Access control: Multi-factor authentication, role-based access
- Network security: Firewalls, IDS/IPS, regular security audits
- Incident response: 24/7 monitoring, rapid containment procedures
- Backup integrity: Encrypted, geographically distributed off-site backups
